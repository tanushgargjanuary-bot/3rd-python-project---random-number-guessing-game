# Python Number Guessing Game

A command-line guessing game. The program selects a random integer from 1 to 100. The player keeps guessing until they find it.

## Run

Requires Python 3.

```bash
python Code
```

## How to play

1. Enter an integer from 1 to 100.
2. The program says whether the guess is too low or too high.
3. Keep guessing until you find the secret number.
4. The program prints the number of guesses.

## Learning goals

This project practises:
- Python's `random` module
- Functions
- `while` loops
- Conditional statements
- Counters and input validation

## Limitations

The program expects integer input. Non-integer input can stop the game. The secret number is generated once when the program starts.
